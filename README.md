## How to Run

1. Install a C compiler such as GCC.
2. Open a terminal in the folder containing the C source file.
3. Compile the program:

   ```bash
   gcc star.c -o star
   ```

4. Run it on Windows:

   ```powershell
   .\star.exe
   ```

Replace `star.c` with the actual filename of the program you want to compile.
